# SkripsiFlow — SaaS Bimbingan Skripsi

Aplikasi bimbingan skripsi terstruktur untuk mahasiswa dan dosen pembimbing dengan 3 pilar inti:
1. **Pengajuan Topik Skripsi**
2. **Jadwal Konsultasi (Anti-Bentrok)**
3. **Monitoring Progress Skripsi (8 Tahapan)**

Dibangun menggunakan **Flutter**, **Supabase (PostgreSQL & Auth)**, dan **Supabase Edge Functions**.
